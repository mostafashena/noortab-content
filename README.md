# محتوای ناشر هدی (HUDA)

این مخزن دو چیز را نگه می‌دارد:

1. **پنل مدیریت** (`index.html` و پوشهٔ `assets/`) که روی GitHub Pages اجرا می‌شود:
   `https://<نام‌کاربری>.github.io/noortab-content/`
2. **محتوای منتشرشده** که پنل خودش می‌نویسد:
   - `content.json`: محتوای امضاشده (ترجمه‌های اصلاح‌شده، احادیث و مناسبت‌های افزوده، تأمل‌ها، اطلاعیه، پیش‌فرض‌ها و فهرست عکس‌ها)
   - `publisher.json`: کلید عمومی ناشر (همین فایل داخل بستهٔ افزونه هم قرار می‌گیرد)
   - `photos/`: عکس‌های پیش‌فرض

این فایل‌ها را دستی ویرایش نکنید. هر تغییری در `content.json` امضا را باطل می‌کند و افزونه آن را نمی‌پذیرد. همهٔ ویرایش‌ها را از طریق پنل انجام دهید.

`privacy.html` سیاست حریم خصوصی افزونه است و نشانی آن در فروشگاه Chrome ثبت می‌شود.

## امنیت

- پنل عمومی است، اما بدون رمز عبور، توکن GitHub و کلید امضای صاحب مخزن هیچ تغییری ممکن نیست.
- کلید خصوصی فقط در مرورگر صاحب مخزن (رمزگذاری‌شده) و در فایل پشتیبان او وجود دارد و هرگز در این مخزن قرار نمی‌گیرد.
- افزونه فقط محتوایی را می‌پذیرد که با کلیدِ داخل بستهٔ خودش امضا شده باشد و شمارهٔ نسخه‌اش از نسخهٔ قبلی کمتر نباشد.
